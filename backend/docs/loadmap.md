### 🗺️ '나의 동행 발자국' 프론트엔드 API 호출 순서

#### [1단계] 설문 제출 및 로드맵 생성 (사용자가 설문 완료 버튼을 누를 때)

• 호출 API: POST /user/survey  
 • 하는 일: 유저가 체크한 답변을 백엔드로 보냅니다. 백엔드는 이 데이터를 바탕으로
AI 상황 요약을 만들고, DB에 '내 로드맵'을 생성한 뒤 그 번호( roadmap_idx )를  
 돌려줍니다.  
 • 프론트 화면: "AI가 맞춤 로드맵을 생성 중입니다..." 같은 로딩

#### [2단계] 로드맵 결과 및 추천 사업 보기 (로딩이 끝나고 결과 화면으로 넘어갈

때)

• 호출 API: GET /roadmaps  
 • 하는 일: 백엔드에 "방금 만든 내 로드맵이랑 추천 사업 목록 줘!"라고 요청
• 프론트 화면: AI가 써준 '상황 요약 텍스트'와 함께, 나에게 딱 맞는 복지 사업들이
카드 형태로 예쁘게 나열된 대시보드 화면을 그리기

#### [3단계] 지원사업 상세 보기 (유저가 리스트에서 사업 카드 하나를 클릭했을 때)

• 호출 API 1: GET /programs/{service_idx}  
 • 호출 API 2: POST /programs/{service_idx}/guide  
 • 하는 일: 1번 API로 이 사업의 기본 대상, 지원 내용 등을 가져와서 화면에  
 표시. 동시에 2번 API를 호출해 AI가 뽑아준 **"전화하기 전 확인해야 할  
 체크리스트"**를 가져와서 하단에 표시.

#### [4단계] 문의 도우미(대본) 열기 (유저가 '상담 준비하기' 버튼을 눌렀을 때)

• 호출 API: POST /programs/{service_idx}/counsel  
 • 하는 일: 전화 공포증이 있는 유저를 위해, AI가 만들어주는 추천 질문 리스트와  
 전화 대본 템플릿을 조회.  
 • 프론트 화면: 유저가 이 대본을 보면서 편안하게 기관에 전화를 걸 수 있는  
 화면(모달창 등) 표시

#### [5단계] 실제 기관 연결 (유저가 '전화 걸기' 버튼을 눌렀을 때)

• API 호출 필요 없음!  
 • 하는 일: 3단계에서 받아온 데이터 중 contact_org (예: 1388) 번호를 이용해,  
 프론트엔드 단에서 <a href="tel:1388">전화걸기</a> 등의 태그로 바로 통화 앱을  
 연결시켜주면 끝

[1단계 ➔ 2단계: '확인됨(checked)'으로 넘어가기]

• 유저 행동: 유저가 특정 사업 카드의 [지원 확인
 가이드(체크리스트) 보기] 버튼을 클릭함.  
 • 프론트 로직: 가이드 모달창을 띄워주는 것과 동시에,
백엔드에 몰래 PUT (상태: checked) 를 쏩니다.  
 • 결과: 이제 이 카드의 상태는 자동으로 checked 가  
 됩니다. (화면의 진행바 1칸 채워짐)

[2단계 ➔ 3단계: '연락완료(contacted)'로 넘어가기]

• 유저 행동: 유저가 [전화 걸기(또는 대본 보기)]  
 버튼을 클릭함.  
 • 프론트 로직: 전화 앱으로 넘겨주는 것과 동시에,  
 백엔드에 PUT (상태: contacted) 를 쏩니다.  
 • 결과: 이제 이 카드의 상태는 자동으로 contacted 가
됩니다. (화면의 진행바 2칸 채워짐)

[3단계 ➔ 4단계: '신청완료(applied)'로 넘어가기]

• 유저 행동: 통화가 끝나고 다시 앱으로 돌아온 유저가
[신청 완료 뱃지 달기] 체크박스나 버튼을 직접  
 수동으로 클릭함.  
 • 프론트 로직: 버튼이 눌리면 백엔드에 PUT (상태:  
 applied) 를 쏩니다.  
 • 결과: 최종적으로 이 카드는 applied 상태가 되며,
화면에서 축하 애니메이션을 터뜨려주거나 [완료된
 항목] 탭으로 예쁘게 옮겨줍니다.
